## 📌 About The Project

**The Perfect Guess** is a beginner-friendly **console-based Number Guessing Game** built using Python.

In this game, the computer generates a random number between **1 and 100**, and the player tries to guess it.

After every valid guess, the program provides a hint:

- 🔼 **Higher Number Please!** → when the guess is smaller than the secret number.
- 🔽 **Lower Number Please!** → when the guess is larger than the secret number.
- 🎉 **Congratulations!** → when the correct number is guessed.

The program also handles invalid inputs, validates the number range, counts valid guesses, and allows the player to play another round.

This project was created as a practical exercise while learning Python through the **CodeWithHarry Python Course**.

# 🔍 Program Breakdown

## 1️⃣ Import the Random Module

```python
import random
```

The `random` module is used to generate the secret number.

---

## 2️⃣ Generate the Secret Number

```python
secret_number = random.randint(1, 100)
```

`random.randint(1, 100)` generates a random integer between **1 and 100**, including both `1` and `100`.

Example:

```text
Secret Number → 29
```

The player does not know this number.

---

## 3️⃣ Initialize the Guess Counter

```python
guesses = 0
```

The `guesses` variable keeps track of how many **valid guesses** the player has made.

Invalid inputs are not counted.

---

## 4️⃣ Display the Game Title

```python
print("🎯 Number Guessing Game")
```

This displays the title of the game in the terminal.

---

## 5️⃣ Create the Game Loop

```python
while True:
```

The game needs to continue asking the player for guesses until the correct number is found.

`while True` creates a loop that continues until it is stopped using `break`.

---

## 6️⃣ Take User Input

```python
guess = int(input("\nGuess the number between 1 and 100: "))
```

The `input()` function receives the player's guess as a string.

The `int()` function converts the input into an integer.

For example:

```text
Input → "50"
After int() → 50
```

---

## 7️⃣ Handle Invalid Input

```python
try:
    guess = int(input("\nGuess the number between 1 and 100: "))

except ValueError:
    print("Please enter valid number!")
    continue
```

If the user enters something like:

```text
abc
hello
python
```

Python cannot convert it into an integer.

This produces a `ValueError`.

Instead of crashing, the `except` block handles the error and displays:

```text
Please enter valid number!
```

Then `continue` starts the next iteration of the loop.

---

## 8️⃣ Validate the Number Range

```python
if guess < 1 or guess > 100:
    print("Please Enter a Number Between 1 and 100.")
    continue
```

The game accepts only numbers from **1 to 100**.

### Examples:

| Input | Result |
| :---: | :--- |
| `0` | ❌ Invalid |
| `150` | ❌ Invalid |
| `50` | ✅ Valid |
| `100` | ✅ Valid |
| `1` | ✅ Valid |

---

## 9️⃣ Count Valid Guesses

```python
guesses += 1
```

The counter increases after the guess passes validation.

For example:

```text
First valid guess  → 1
Second valid guess → 2
Third valid guess  → 3
```

Invalid input such as `abc` or `150` is **not counted**.

---

# 🔄 Guess Comparison

The program compares the player's guess with the secret number.

```python
if guess < secret_number:
    print("Higher Number Please!")

elif guess > secret_number:
    print("Lower Number Please!")

else:
    print("\n🎉 Congratulations!")
```

### 🔼 Guess is Smaller

If:

```text
Guess = 20
Secret Number = 29
```

Output:

```text
Higher Number Please!
```

---

### 🔽 Guess is Larger

If:

```text
Guess = 50
Secret Number = 29
```

Output:

```text
Lower Number Please!
```

---

### 🎯 Guess is Correct

If:

```text
Guess = 29
Secret Number = 29
```

Output:

```text
🎉 Congratulations!
```

---

# 🏆 Display Final Result

After the correct guess:

```python
print(f"You Guessed the Correct Number: {secret_number}")
print(f"It took {guesses} guesses to guess the number")
```

The program displays:

- The correct number
- Total number of valid guesses

Example:

```text
🎉 Congratulations!
You Guessed the Correct Number: 29
It took 6 guesses to guess the number
```

---

# 🔄 Play Again

After winning, the player can decide whether to play another round.

```python
again = input("Play Again? (yes/no): ").lower()

if again != "yes":
    break
```

### If the user enters:

```text
yes
```

The loop continues and another round starts.

### If the user enters:

```text
no
```

The `break` statement stops the loop and the program ends.
